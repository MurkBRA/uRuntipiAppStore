# Satoshi Dashboard

> Real-time Bitcoin analytics dashboard

Satoshi Dashboard is a comprehensive, real-time Bitcoin analytics platform that brings together 32+ key metrics into a single, beautifully designed interface. Track live BTC price, sats per dollar, block height, hash rate, network difficulty, circulating supply, and the Fear & Greed index — all updating in real time from multiple data sources.

Dive deep into mempool analytics with a live status gauge showing usage percentage, pending transactions, virtual size, and fee estimates across economy, normal, and priority tiers. Visualize the Bitcoin mempool queue with interactive charts broken down by fee bands, and explore block-level fee heatmaps for a granular view of network activity.

Monitor the global Bitcoin network with an interactive node map showing 21,000+ nodes across every country, with breakdowns by IPv4, IPv6, full nodes, and pruned nodes. Compare BTC against gold, analyze housing affordability in Bitcoin terms, and explore cycle analysis tools — all from one dashboard.

Satoshi Dashboard is self-hosted, open-source, and designed for bitcoiners who value sovereignty and want a single place to monitor the Bitcoin ecosystem, with live data sourced from public APIs.
