# Manifold Fedimint Guardian

> Run guardian seats across many federations from one machine.

Manifold Fedimint Guardian lets you run guardian seats across multiple Fedimint federations from a single machine. Advertise your available capacity, get selected for federations, provision guardian seats locally, and earn fees for the seats you operate. Each seat runs as a distinct guardian with its own fedimintd instance and key, so you can serve multiple communities and earn fees.

As part of a federation, you participate in the consensus with other guardians. No guardian controls a federation’s funds alone or sees users’ holdings.

Manifold Fedimint Guardian is part of Manifold, the protocol for accelerating the deployment and decentralisation of Fedimint federations.

## Default Credentials
- **Password**: Generated automatically via the `APP_PASSWORD` field in your Runtipi app configuration.

## Inter-App Connections

This package integrates with **bitcoin** on the Runtipi shared network (`tipi_main_network`). You can customize the target hostnames, ports, and RPC credentials in the install form fields.
