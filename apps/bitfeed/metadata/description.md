# Bitfeed

> A beautiful mempool visualizer and block explorer

A self-hosted version of Bitfeed - the open source mempool visualizer & block explorer available at https://bitfeed.live.

Watch as new transactions drop into your node's mempool, before being packaged into newly mined blocks.

Monitor Bitcoin network activity, explore blocks and transactions, or simply enjoy a soothing Bitcoin screensaver.

## Inter-App Connections

This package integrates with **bitcoin** on the Runtipi shared network (`tipi_main_network`). You can customize the target hostnames, ports, and RPC credentials in the install form fields.
