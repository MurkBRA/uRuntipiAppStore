# Calibre-Web Automated

> An automated, all-in-one e-book library

Calibre-Web Automated combines Calibre-Web with automated e-book ingest, conversion, metadata management, and library tools.

Sign in with the default credentials shown by Runtipi and change the password after your first login.

Add books by uploading them in the app or by dropping them into the book ingest folder. CWA imports them into your library and then deletes them from the ingest folder, so don't download directly into it. By default the library and ingest folder live in the app's own storage. You can point either one at a folder of your own in the app's settings.
