# Originless

> Private, decentralized file sharing for Nostr and the web

One all-in-one storage backend you can drop into anything: your own apps, screenshot tools, pastebin-style pastes, Nostr clients, Reddit posts, forum embeds-anything that needs durable, anonymous file hosting. Built on IPFS with 95% bandwidth reduction compared to previous versions.

For File Drop users: Originless replaces the developer's previous Umbrel app listing for File Drop. If File Drop is installed on your Umbrel, uninstall it before installing Originless because both apps cannot run at the same time.

Advanced IPFS note: For direct external IPFS connectivity, forward TCP and UDP port 4001 on your router to TCP and UDP port 4003 on your Umbrel.
