# usocial

> Read. Listen. Pay back.

The podcast client and feed reader for your personal server. With Lightning Network support.

- Simple interface (minimalist HN-like design)
- Optionally multi-user
- Decentralized karma
- Clean code (Python / Flask / SQLite)
- Search podcasts from Podcast Index
- Support for the Podcasting 2.0 value tag, sending Bitcoin payments to podcast creators over the Lightning Network

## Default Credentials
- **Password**: Generated automatically via the `APP_PASSWORD` field in your Runtipi app configuration.

## Inter-App Connections

This package integrates with **lightning** on the Runtipi shared network (`tipi_main_network`). You can customize the target hostnames, ports, and RPC credentials in the install form fields.
