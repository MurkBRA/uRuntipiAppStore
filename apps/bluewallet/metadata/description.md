# BlueWallet Lightning

> Connect BlueWallet to your Lightning node

Run BlueWallet in the most private and secure way possible by removing 3rd parties and connecting it directly to your Runtipi's Lightning node.

You can pair multiple BlueWallet accounts, so your friends and family can pair their BlueWallet with your Runtipi for a trust-minimized setup.

## Inter-App Connections

This package integrates with **lightning** on the Runtipi shared network (`tipi_main_network`). You can customize the target hostnames, ports, and RPC credentials in the install form fields.
