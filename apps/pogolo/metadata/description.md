# pogolo

> Local Go-based SV1+SV2 solo pool

solo db-less bitcoin-only mining pool, meant for lan swarms, not the internet;

start it, point your miners to it, and watch the logs roll by

think of this as public-pool but minimal and for self-sovereign nerds

## Inter-App Connections

This package integrates with **bitcoin** on the Runtipi shared network (`tipi_main_network`). You can customize the target hostnames, ports, and RPC credentials in the install form fields.
