# Public Pool's Web

> Modern web interface for managing your Public Pool's data

Public Pool's Web provides a sleek, user-friendly interface for managing and monitoring your Public Pool's data. 

Built with Rails 8.1 and modern web technologies, it offers real-time updates, detailed analytics, and comprehensive pool management features.

Features:
  - Add user
  - Add worker
  - Change theme
  - Sidekiq web interface ( to check background jobs, usually you do not mess with it )

This is a hobby project!

## Inter-App Connections

This package integrates with **public-pool** on the Runtipi shared network (`tipi_main_network`). You can customize the target hostnames, ports, and RPC credentials in the install form fields.
