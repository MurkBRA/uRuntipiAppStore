# Bassin

> Solo Bitcoin Mining Pool (ckPool)

A zero-fee Bitcoin solo mining pool for Umbrel. Run your own ckPool at home.

No setup, no hassle.
  - Make sure your Bitcoin Node is fully synchronized and running
  - Install the app, then follow the on-screen instructions
  - Be part of decentralized mining


Check out the FAQ page: https://github.com/blockdyor/bassin/wiki/FAQ

For academic and research purposes only.

## Inter-App Connections

This package integrates with **bitcoin** on the Runtipi shared network (`tipi_main_network`). You can customize the target hostnames, ports, and RPC credentials in the install form fields.
